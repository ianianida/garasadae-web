# 가라사대

사용자가 고민을 적고 성경 말씀을 뽑아, 자신의 선택을 후련하게 정할 실마리를 얻는 웹 서비스입니다.

현재는 기존 모바일 앱을 바탕으로 웹 서비스를 다시 기획하는 단계입니다. 구현과 서비스 배포는 아직 시작하지 않았습니다.

## 제품의 핵심

- 나에게 딱 맞는 말씀이 운명처럼 느껴지고, 사용자가 어느 한쪽 선택으로 마음을 정할 수 있어야 좋은 뽑기입니다.
- 서비스가 하나님의 뜻이나 행동 결론을 대신 선언하지 않습니다. 사용자가 말씀을 읽고 해석합니다.
- 구절 분류는 카테고리 이름과의 관련성만으로 판단하지 않습니다. 카테고리마다 다양한 구체 고민을 만들고, 각 고민과 말씀의 조합에서 선택 방향과 후련함을 검증합니다.
- 최소 기록은 고민·말씀·날짜와 당시 생각 또는 결정 한 줄입니다. 일기 링크 공유를 검토하고 있습니다.

## 선택한 웹 기술

Next.js App Router와 TypeScript, Supabase PostgreSQL/Auth/RLS, Vercel을 사용합니다. 구체적인 로그인 방식, AI 공급자, 성경 역본, 도메인과 사업 모델은 공동 기획 중입니다.

## Git으로 작업하기

기본 브랜치는 `main`입니다. 구현 작업은 `codex/작업명` 브랜치에서 진행하고, 의미 있는 변경 단위로 커밋합니다. `.env`, 비밀 키, 의존성, 빌드 결과, 로컬 백업은 Git에 올리지 않습니다.

기획 문서도 코드와 함께 이 저장소에서 변경 이력을 관리합니다.
