# 성경 전체 검수와 출시 완료 기준

## 사용자가 정한 범위

2026-10-08: 작은 20구절 묶음으로 먼저 출시하자는 제안을 채택하지 않았다. **개역한글 성경 전체 구절을 검수·필터링하고 서비스에 도입한 뒤 출시한다.** 사용자가 직접 전수 검수하지 않으며, Codex가 인터뷰의 기준을 토대로 개별 말씀을 사용자 입장에서 엄밀하게 평가한다.

이는 전체 성경의 모든 절을 추첨 후보로 넣으라는 뜻이 아니다. 모든 절을 검토 대상에 놓고, 설명 없이 생활의 선택과 연결할 실마리가 있는 절을 가려 도입한다.

### 대한성서공회 개역한글 전체 본문 대조

2026-10-08에 공식 공개 성경읽기의 66권·1,189장 본문과 작업용 전체 자료를 대조했다. 판본 선택이 개역한글인 것을 확인하고, 소제목·각주 표지·대체 각주를 본문과 구분했다. NFC와 공백 제거 후 전체 본문에서 문자 차이를 발견하지 않았다. 이는 자동 원문 대조이며 위의 개별 사용자 경험 검수를 대신하지 않는다.

공식 판본에서 합쳐 표기하는 19개 묶음은 두 절 또는 세 절의 같은 본문을 번호마다 저장한 항목이었다. 31,102개 번호를 공식 표기 단위로 세면 31,081개이며, ‘없음’ 표시는 그 안에 포함된다. 작업용 원장은 그대로 보존하고, 도입 때 합친 본문을 서로 다른 추첨 후보로 중복 취급하지 않는다. 요나서는 공식 페이지의 책 선택자가 사용하는 `jnh`와 작업용 식별자 `JON`을 대응해 확인했다.

확인 기록은 `data/source/krv-publisher-audit.json`이다. 장별 공식 URL·HTML 해시·정규화한 본문 해시와 합친 절 대응을 보존한다. 재현은 `node scripts/check-publisher-corpus.mjs --all` 및 `node scripts/save-publisher-receipt.mjs`로 수행한다.

## 개별 절 평가 기준

1. 절 전체를 풀이 없이 읽을 수 있는가. 일부 좋은 단어 뒤에 연결을 깨는 긴 문장이 붙는지도 읽는다.
2. 앞뒤 문맥에서 누가 누구에게 말하는지, 조건·반어·인용·이야기의 역할을 확인한다. 개인적 상황 연결과 성경의 본래 뜻을 구별한다.
3. 구체 고민의 선택지·양쪽 부담·명시된 제약에 대조한다. ‘돈’·‘옷’ 같은 같은 단어 자체를 충분함으로 삼지 않는다.
4. 원문에 없는 기회·돈·기한·상대의 마음을 넣어야만 연결되는지 확인한다.
5. 바로 또는 잠시 생각한 뒤 선택에 실마리가 보이는가. 고른 쪽이 원래 원하는 방향과 같을 필요는 없다.
6. 뜻밖의 적합함, 신비함·재미, 후련함과 첫 결과를 받아들일 충분함을 구별한다. 후련함이 즉시 크지 않아도 충분했던 F·O의 반응을 보존한다.
7. 사용자에게 선택의 방향을 읽을 여지가 있는가. 서비스의 행동 결론·하나님의 직접 명령 설명은 덧붙이지 않는다.
8. 생성 고민의 예상 평가, 기존 판본별 사전 반응, 실제 배포 후 피드백을 구분한다.

## 기록 형식

각 절에 본문 해시, 검수 버전·도구, 전체 절 판단, 문맥 확인, 연결되는 구체 고민과 읽을 실마리, 연결을 방해하는 부분, 채택·보류·제외 근거를 남긴다. 기계적인 빈 항목 확인과 의미 평가는 따로 기록한다. 아직 읽고 평가하지 않은 절은 `pending` 상태다.

보류 항목을 보류 근거 없이 제외 숫자에 합쳐 완료율을 높이지 않는다. 자동 보조 평가를 Codex의 직접 재검토나 실제 사용자 반응으로 표시하지 않는다.
