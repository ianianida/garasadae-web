# 개역개정 데이터 출처와 도입 조건

> 확인일: 2026-10-08. 판본 선호와 확보 경로를 기록한 기획 자료다. 서비스용 전체 본문 데이터셋의 반입·사용허가·비용 지출은 아직 완료되지 않았다.

## 사용자가 정한 방향

> 새번역이 아니고 개역개정인가보다. 가능하면 개역개정판 성경 데이터셋을 활용해줘.

- 우선 활용할 판본은 개역개정이다. 이후 말씀 비교에는 확인된 개역개정 공식 본문을 사용한다.
- 이전 개역한글 표본과 사용자 반응은 그대로 보존한다. 이를 개역개정의 평가로 바꾸지 않는다.
- 데이터 확보가 어려운 경우의 대체 판본과 사용료 지출은 아직 함께 결정하지 않았다.

## 공식 자료에서 확인한 사항

| 항목 | 확인한 내용 | 근거 |
|---|---|---|
| 판본 | 대한성서공회 성경플랫폼은 개역개정판(1998)을 제공하는 역본으로 안내한다 | [자료 안내](https://bible.bskorea.or.kr/user_guide/resource_guide) |
| 이용 조건 | 권리자는 번역 본문을 이용할 때 이용 방법과 범위에 맞는 허락·조건을 확인하도록 안내한다 | [저작권 안내](https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_1) |
| 웹 본문 서비스 | 웹을 통한 성경 본문 제공을 포함하는 항목의 일반 안내는 번역본당 1년 100만 원이다 | [허가조건·사용료](https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_3) |
| 문의 경로 | 저작권 담당 전화 02-2103-8730, 이메일 kbscopyright@bskorea.or.kr | [사용허가 절차](https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_4) |

위 금액은 공표된 일반 안내다. 가라사대에 대한 실제 견적·계약 조건으로 확정한 것이 아니다. 한 번에 구절 하나를 표시하고 개인 기록과 링크 공유를 제공하는 형태에 적용될 범위, 무료 서비스에 적용할 별도 조건, 데이터 파일·API 제공 여부는 아직 확인하지 못했다.

## 공개 데이터 후보 조사

| 후보 | 확인한 상태 | 도입 판단 |
|---|---|---|
| [dev-dooD/bible-crawler](https://github.com/dev-dooD/bible-crawler) | 개역개정·새번역을 수집한 JSON 파일과 수집 코드가 공개돼 있다. 작성자는 합쳐진 절과 빈 절에 관한 처리도 설명한다 | 서비스 사용허가와 본문 정확성을 아직 확인하지 못해 반입 전 검토가 필요하다 |
| [stranger828/bibleAPI](https://github.com/stranger828/bibleAPI/blob/main/README.md) | 개역개정 JSON을 활용하는 프로젝트다. 본문 저작권은 코드의 사용 조건과 별도로 확인해야 한다고 작성자가 설명한다 | 공개 파일의 존재만으로 서비스 이용 가능하다고 채택하지 않는다 |
| [Bible Sidecar KR](https://github.com/KORThomasJeong/bible-sidecar-KR/blob/main/README.md) | 개역개정을 지원하지만 본문을 포함하지 않고 사용자가 준비한 로컬 JSON을 읽는다 | 개역개정 데이터셋을 제공받는 경로가 아니다 |

이번 조사 범위에서 우리 웹서비스에 이용할 수 있는 허가까지 확인된 무료 공개 데이터셋은 찾지 못했다. 위 저장소의 외부 코드를 실행하거나 전체 본문 파일을 가져오지는 않았다.

## 권리자에게 확인할 항목

아래는 문의를 준비하기 위한 항목이며, 실제 문의는 아직 보내지 않았다.

1. 무료 웹서비스에서 사용자가 입력한 고민에 따라 검수된 후보 중 말씀 한 구절을 추첨해 표시하는 형태의 허가 조건.
2. 본문을 서버의 데이터베이스에 저장하고, 고민·말씀·날짜·사용자의 한 줄 생각을 함께 보관하는 범위.
3. 사용자가 자신의 기록 링크를 공유할 때 구절 원문을 표시하는 범위와 필요한 출처 표시.
4. 개역개정 정식 본문 파일 또는 API의 제공 여부, 제공 형식·판차·업데이트 방법.
5. 공개 안내의 사용료가 이 서비스에 어떻게 적용되는지와 다른 조건의 가능성. 교회 맞춤 제공은 현재 탐색 후보이므로 그 경우의 조건은 별도 확인.
6. 성경 본문을 분류·검수하기 위한 내부 이용 범위. 초기 AI는 고민 구조화만 담당하며 말씀 후보 평가·해설 생성은 하지 않는다는 현재 설계 설명.

## 데이터 확보 뒤의 검토 절차 제안

- 권리자가 제공하거나 사용 범위가 확인된 원문을 기준으로 판본·판차·출처·확인 시점을 남긴다.
- 책·장·절 식별자, 중복·누락, 합쳐진 절, 빈 절과 주석을 구분해 대조한다. 누락된 본문을 추정해 채우거나 다른 판본을 섞지 않는다.
- 공식 본문과 데이터 파일이 다른 항목은 확인한 뒤 후보로 사용한다. 사용허가와 공개 재배포 범위를 구분해 원문 파일의 관리 위치를 정한다.
- 확보한 본문은 다양한 `구체 고민 × 말씀` 사례와 대조한다. 기존 평가의 판본을 보존하고, 개역개정에서 얻은 반응을 별도로 기록한다.
- 후보 자격·가중치·통과 기준은 이 출처 조사만으로 변경하지 않는다. 사용자와 함께 판단한다.
