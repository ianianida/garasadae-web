### 진행 중

사무엘하·예레미야·사도행전의 진행 지점 이후를 세 Codex 작업이 계속 직접 읽는다. 위 확인 시점의 부분 저장분은 사무엘하 575절(마지막21:17)·예레미야150절(6:7)·사도행전774절(21:33)이다. 이사야도 전부 저장했다. 이전 `*_oct25` 세 담당이 실제 목록과 재개 대상으로 없음을 각각 확인했고 현재 일반 사용 가능 상태를 확인한 뒤 같은 세 범위를 `review_gen_oct27`·`review_wisdom_oct27`·`review_nt_oct27`이 이어받았다. 실행 안내만을 완료로 세지 않으며 새 범위나 중복 담당은 추가하지 않았다. `readability`는 `clear`·`thinkable`·`needs_explanation`이다. 새 B031(받은 도움과 하나님께 감사한 마음을 모임에서 말할지)·C023–C026(소식 알림과 할 일·미정 일정의 조건부 약속·공동비용 공식 논의·배웅의 감정 표현)은 생성 사례이며 실제 반응이 아니다. 사용자의 작업 계속 지시는 유효하다. 위 숫자는 확인 시점 기록이고 이후 실시간 수치가 아니다.

## 공개 배포까지 남은 일

1. 나머지 절의 개별 검수.
2. 모든 후보·보류의 통합 재검토.
3. 채택 구절의 전체 본문과 검수한 구체 고민을 실제 ② 후보 규칙에 연결.
4. 같은 확률, 최근 5회 회피, 재뽑기 다른 본문 규칙을 최종 자료로 확인.
5. 전체 출시 검사 통과 후 공개 배포와 실제 로그인·뽑기·기록·공유·피드백 확인.

회원가입·로그인·기록 동기화·선택 공유의 로컬 검증과 원문 대조 도구는 준비돼 있다. **전체 콘텐츠 검수와 후보 통합은 아직 끝나지 않았으며 공개 배포도 아직 수행하지 않았다.** 후보의 충분함은 합성 고민에 대한 Codex의 사전 예상이고 실제 사용자 반응과 구분한다.
