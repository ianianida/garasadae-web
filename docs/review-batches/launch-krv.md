# 첫 웹 배포: 개역한글 조합 검수

작성일: 2026-10-08. **출시 후보안이며 최종 채택은 사용자와 결정한다.**

**후속 정정:** 사용자는 작은 구절 묶음의 출시안을 채택하지 않고, 성경 전체를 절별로 엄밀하게 검수·필터링해 도입한 뒤 출시하자고 요청했다. 아래 20구절안은 초기 비교 자료로 보존하며 출시 완료 기준으로 사용하지 않는다. 전체 검수 작업은 `docs/full-corpus-review.md`에서 추적한다.

## 검수 범위와 근거

- 본문 22개를 개역한글 출처와 대조했다. 문장이 어렵거나 문장 전체의 연결이 끊기는 2개를 보류해 **운영 구절은 20개**다.
- `src/data/review-cases.ts`의 생성 고민 16개를 아래에 그대로 인용하고, 각 고민의 첫 후보와 재뽑기 확장 후보를 전체 문장 기준으로 검토했다. 실제 이용자가 읽고 평가한 자료로 간주하지 않는다.
- 이전 개역개정 평가를 개역한글의 새 사용자 평가로 복사하지 않았다. 디모데전서 6:8·잠언 25:16·19:2의 기존 개역한글 반응, 마태복음 6:34·전도서 3:13·누가복음 12:34·잠언 21:5의 다른 판본 반응은 각각 구분한다.
- 아래의 **첫 후보/확장**은 Codex의 사전 판단이다. 확장은 연관성이 없는 구절을 허용한다는 뜻이 아니다. 생각하면 연결되고 첫 결과로도 받아들일 가능성이 있는 조합을 제안한다. 실제 충분함은 이용자의 피드백으로 확인한다.
- 각 문장의 성경 문맥과 사용자가 자기 상황에 연결하는 해석은 별개다. 아래의 연결 가설은 내부 검수 자료이며 결과 화면에 제시하지 않는다.
- 빠진 조건을 지어내야 연결되는 조합, 특정 단어 하나만 맞고 뒤 문장이 끊기는 조합, 풀이 없이 읽기 어려운 조합을 우선 보류한다. 숫자로 성공률을 만들어 발표하지 않는다.

> 사고 싶은 자켓이 있고 쓸 돈도 따로 모아뒀다. 자주 입을 것 같지만 최근에도 옷을 샀다는 생각 때문에 마음이 걸린다. 안 사면 아쉬울 것 같다.

## 3. 기본 확장의 다른 고민 대조

기본 확장도 카테고리 단어만으로 통과시키지 않는다. 아래는 각 기본 후보를 다른 구체 갈등에서 읽었을 때의 사전 대조이며 만족도 측정이 아니다.

| 구체 갈등 | W: 짐을 맡김 | AB: 계획과 걸음 | V: 수고·쉼 |
| --- | --- | --- | --- |
| G01 구매 죄책감 | 죄책감의 짐을 놓는 방향; 옷의 재미는 약함 | 구매 계획의 책임 부담을 맡기는 방향 | 최근 구매를 고민하는 무거운 마음의 쉼; 육체 수고는 미언급 |
| G02 생활비 부족 | 현실의 부족이 사라진다고 약속하지 않고 걱정을 맡김 | 지출 계획과 알 수 없는 걸음을 나눠 읽음 | 돈 부족으로 무거운 마음을 잠시 쉬게 할 실마리 |
| G03 할인·사용 불확실 | 놓치는 아쉬움의 짐을 놓을 수 있음 | 오늘 구매와 다음 행동을 계획해 맡김 | 할인에 쫓기는 마음을 잠시 쉬게 할 연결 |
| G04 내일 피로 | 내일의 피곤함을 걱정하는 짐 | 이미 끝낸 일과 공연 동선을 계획함 | 내일 피로와 오늘 쉬기의 연결 |
| G05 당일 미완료 보고서 | 두 일의 부담을 맡기되 제출 기한은 변하지 않음 | 참석 계획과 실제 시간의 불확실함 | 일과 즐거움 사이의 무거운 마음에 쉼 |

| G07 기다리기 피로 | 반복 확인을 내 짐으로 보고 맡김 | 매물 가격 계획을 놓고 기다림 | 지친 확인을 멈추고 쉬는 실마리 |
| G08 필요한 돈의 기한 | 무거운 돈 걱정을 맡김; 돈 마련은 보장 없음 | 매각 계획을 세우고 불확실한 결과를 맡김 | 압박에 쉼; 기한을 없애는 뜻으로 설명하지 않음 |
| G09 거래 약속·더 높은 제안 | 손해·약속에 대한 부담을 맡김 | 먼저 세운 거래 계획과 다음 걸음을 생각함 | 이익과 약속 사이 무거운 마음을 쉬게 함 |
| G10 사과의 민망함 | 거친 말 뒤의 부담을 맡김 | 먼저 말을 걸 계획과 수용 여부를 맡김 | 후회와 민망함으로 무거운 마음에 쉼 |

| G13 잠 부족 | 시험 부담을 맡김 | 공부 계획과 내일의 걸음 | 수고와 피로에 가장 직접적인 연결 |
| G14 치료 피로 | 몸·마음의 짐을 맡김 | 계속/다른 선택 계획과 불확실한 결과 | 수고·피로에 직접 연결; 치료 중단 해설 없음 |
| G15 첫 지원 두려움 | 잘할지 모르는 두려움의 짐 | 지원 계획과 처음의 걸음에 직접 연결 | 처음의 두려움이 마음의 부담이라는 비유 |

모든 상황에서 같은 정도로 놀랍다고 판단하지 않는다. 기본 확장으로 간 결과는 `stage=2`와 해석 실패/일일 한도 등의 `analysisMode`를 피드백에 남겨, 해당 원인을 따로 볼 수 있다.

## 5. 첫 추첨 규칙안과 출시 판단

1. Luna는 고민의 선택지·이유·부담과 명시 조건만 구조화한다. 본문·후보·순위는 모델에 주지 않는다.
2. 원문에 그대로 있는 근거를 확인한 조건으로 14개 검수 규칙을 적용한다. 후보는 동일 구절 식별자로 중복 제거한다.
3. 첫 후보가 있으면 그 안에서 최근 5번을 가능할 때 피한다. 후보 전부가 최근라면 다시 허용한다.
4. 같은 고민 재뽑기는 직전 구절을 항상 제외한다. 다른 첫 후보가 없으면 해당 조합의 확장 후보, 그래도 없으면 위의 기본 3개로 넓힌다.
5. 남은 서로 다른 후보 N개는 각각 1/N이다. 관련성이 더 높아 보였다는 이유로 확률을 높이지 않는다.
6. AI 실패·일일 한도 초과에도 결과는 기본 확장에서 뽑되, 피드백 자료에는 원인을 남긴다. 재뽑기는 같은 고민의 해석을 재사용한다.

**Codex 검수 결론:** 단어 매칭보다 선택을 막는 부담·시점을 보존하는 초안으로 구현 가능하다. 20개 작은 구절 묶음과 새로운 조합의 충분함은 모든 사용자에게 검증된 상태가 아니다. 기존 반응, 예상 판정, 실제 배포 후 피드백을 분리해 출시 자료를 내보낼 수 있다.

**공동 결정할 남은 사항:** 이 검수안을 첫 공개 묶음으로 채택할지, 새 조합을 직접 읽는 추가 검수가 필요한지. 최종 채택 답변 전에는 ‘사용자 승인 완료’로 표기하거나 운영 배포를 완료했다고 보고하지 않는다.
